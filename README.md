# MoodMatch

Mood-based entertainment recommendation platform backend.

## Quick Start

```bash
cd backend
npm install
npm run seed     # Seeds sample entertainment catalog (if MongoDB is running)
npm test         # Runs full 64-assertion test suite
npm run dev      # Starts server on port 5000 with nodemon
```

For complete API documentation, environment variables, and architecture details, see [backend/README.md](file:///c:/Users/drish/OneDrive/Desktop/mood_backend/backend/README.md).
